## ✨ Características Principales

-   **⚡ Alto Rendimiento:** Utiliza Next.js App Router para una carga ultrarrápida.
-   **🎨 Diseño Premium:** Estética limpia y moderna optimizada para dispositivos móviles (Mobile-First).
-   **🌓 Modo Oscuro:** Soporte nativo para temas claro y oscuro que se adaptan a la preferencia del usuario.
-   **📦 Catálogo Dinámico:** Grilla de productos con descripciones detalladas y precios mayoristas.
-   **💳 Pagos Flexibles:** Soporte visual para los principales medios de pago (VISA, MasterCard, MercadoPago, Go Cuotas, Rapipago, Pago Fácil).
-   **📝 Pedidos Interactivos:** Formulario intuitivo para que los clientes realicen sus pedidos y consultas directamente.
-   **🛠️ Código de Calidad:** Arquitectura escalable basada en componentes reutilizables y tipado estricto con TypeScript.

## 🛠️ Tecnologías Utilizadas

-   **Framework:** [Next.js 15+](https://nextjs.org/) (App Router)
-   **Interfaz:** [React 19](https://react.dev/)
-   **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)

## 🚀 Instalación y Desarrollo Local

Sigue estos pasos para ejecutar el proyecto en tu máquina local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/carlosdm121/Insumos-Estetica.git
   cd Insumos-Estetica
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   La aplicación estará disponible en `http://localhost:3000`.

4. **Construir para producción:**
   ```bash
   npm run build
   npm run start
   ```
